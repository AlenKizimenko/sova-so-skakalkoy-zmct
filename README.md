# Один анонс — несколько площадок

Исследовательский AI-проект для практикующих экспертов: психологов, коучей, преподавателей и ведущих групп. Идея проекта — превратить свободный текст анонса в структурированные данные мероприятия и подготовить на их основе материалы для разных каналов.

## Какую проблему решает проект

Эксперт составляет один анонс, а затем вручную адаптирует его для соцсетей, рассылки и страницы мероприятия. При переносе встречи приходится повторно редактировать каждый вариант. Это отнимает время и создаёт риск расхождения дат, адресов и цен.

Проект исследует, как сократить эту работу с помощью языковой модели и общего набора данных мероприятия.

В исследовании используется концепция «Один анонс — пять площадок и страница мероприятия». Первые эксперименты ограничены тремя форматами: **ВКонтакте, email и страница сайта в Markdown**.

## Целевой сценарий

1. Эксперт вводит анонс в свободной форме.
2. Модель извлекает дату, время, место, стоимость и другие поля в JSON.
3. Неясные или противоречивые данные проходят уточнение у эксперта.
4. На основе проверенных данных формируются тексты для выбранных каналов.
5. При изменении условий обновляется общая карточка мероприятия, затем — связанные тексты.

Уточнение данных, хранение карточки и согласованное обновление каналов относятся к планируемому развитию проекта.
